# kpocrm - Fidal CRM Account Plan

Account plan and organigram for **Fidal** (largest French business law firm) from the perspective of a **DocuSign France Account Executive**.

## Files

| File | Format | Purpose |
|------|--------|---------|
| `fidal_crm_account_plan.json` | JSON | Complete structured data - importable into Salesforce, HubSpot, Pipedrive |
| `fidal_contacts_import.csv` | CSV | Contact list ready for CRM import (22 contacts with roles and priorities) |
| `FIDAL_ORGANIGRAM.md` | Markdown | Visual organigram, buying center map, engagement playbook |

## Key Facts

- **Revenue**: EUR 283M | **Employees**: 2,300 | **Lawyers**: 1,400
- **Offices**: 87 across France + Overseas | **Regional Divisions**: 12
- **Tech Stack**: Azure Cloud (ITS Integra), Fidal IA (Sopra Steria Next), 150 SaaS apps
- **Primary Contact**: Stephane Mariotto (DSI/CIO/CISO)
