# kpocrm

- `/` : **On regarde quoi ?** : le meilleur de Netflix, Prime Video et Disney+.
- `/vocal/` : **Vocaux** : transcription des messages vocaux WhatsApp (Opus) directement sur le téléphone, avec Whisper (transformers.js). Une fois installée sur Android, l'app apparaît dans « Partager » de WhatsApp. Le résumé par Claude est optionnel : il faut ajouter sa clé API dans les réglages.
