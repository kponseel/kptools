Réglages

Téléchargé une seule fois, puis tout se passe sur ton téléphone. L'audio n'est jamais envoyé sur internet. Les gros modèles sont plus précis mais plus lents, et demandent un téléphone récent : fais le premier téléchargement en Wi-Fi. Cohere ne détecte pas la langue tout seul : choisis-la ci-dessous.
Modèle Claude Haiku 5.5 : moins d'un dixième de centime par vocal. Seul le texte transcrit est envoyé à Anthropic, jamais l'audio. La clé reste sur ce téléphone.
Comment obtenir une clé ?
  1. Crée un compte sur console.anthropic.com.
  2. Billing → ajoute un peu de crédit (5 $ suffisent pour des milliers de vocaux).
  3. Conseillé : Limits → fixe une limite de dépense mensuelle basse.
  4. API Keys → Create Key, copie la clé (elle commence par sk-ant-) et colle-la ici.
